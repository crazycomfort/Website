HVAC System Replacement

1. What This Service Is

System replacement is removing existing HVAC equipment and installing new, right-sized equipment that meets current requirements. It includes setup, testing, and documentation of the installation steps.

2. Common Symptoms or Triggers

  • Frequent breakdowns or repeated part failures
  • Major refrigerant leaks or obsolete refrigerant
  • Equipment age beyond typical service life with declining performance
  • Uneven temperatures or airflow that cannot be corrected by repair
  • Rising energy use compared to prior seasons
  • Failed compressor, coil, or heat exchanger where repair is impractical

3. How We Diagnose (Critical)

  1. Inspect existing equipment (model/serial, condition, age indicators).
  2. Check duct condition and size; note visible restrictions or damage.
  3. Measure current performance: airflow observations, temperature split, system response.
  4. Assess electrical condition (wiring, breakers, disconnect) for suitability.
  5. Document any leaks, corrosion, failed components, or safety concerns.
  6. Confirm home needs: square footage, load considerations, comfort/IAQ priorities.
  7. Document all findings with photos/video for review.

4. Options We May Recommend

  • Replace outdoor unit, indoor coil/air handler, and thermostat as a matched system.
  • Update line set or flush existing if condition allows, based on inspection.
  • Duct repairs or modifications if airflow issues are documented.
  • Condensate management updates (drain, pan, float switch) if needed.
  • Electrical updates (disconnect, whip, breaker) if current setup is unsuitable.

5. What We Will NOT Sell

  • No upsized equipment without load/duct support.
  • No duct changes without measured or visible need.
  • No add-on products without a documented issue they address.
  • No replacements without evidence the existing system is failing or impractical to repair.

6. FAQs

  • How do you decide on system size? By load considerations and existing duct capacity; we avoid oversizing.
  • Do you reuse line sets? Only if condition and compatibility allow; otherwise we replace.
  • What about ducts? We repair/modify if airflow or condition requires it; we do not change ducts without cause.
  • How long does a replacement take? Typically one day for a standard split system; more if duct or electrical work is needed.
  • Do you handle disposal and permits? Yes, removal and required permits are part of the process when applicable.
  • Will you recommend add-ons? Only if a documented issue warrants it (e.g., drain safety if previous overflow).

7. Evidence Block

We document the condition of the old system, installation steps, tests, and final readings with photos or video. You see what we see before and after the replacement so every recommendation is evidence-based.
